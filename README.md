# Note-searcher

Small app for searching through Markdown files, this is useful for AI agents.

## Test Data

A reference library of test data is available in `testdata/reference-library/` containing thousands of markdown files from Kubernetes and Azure documentation. See [`testdata/README.md`](testdata/README.md) for details on generating and using the test data.

Test queries for the reference library are provided in [`testdata/test-queries.md`](testdata/test-queries.md).
